The mechanic I prototyped was the battlebox system from deltarune. It is essentially a mini bullet hell style gameplay loop that has a few different attacks that the player must dodge.
If we continue this prototype then I would like to add the tp system that the game has and maybe eventually party members and an opponent! 
I kept everything within scope for this prototype, it took me a little more time than I thought it would but that was mostly because I was learning how interfaces worked.
I used interfaces to detect which kind of projectile the player was hit by and what kind of damage they should take in response.
Delta time was used for both projectiles and the player, and Start/Awake was used across most scripts to initialize things in the proper order.
